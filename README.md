# HotspotGuard 屏幕 / USB 触发热点

Windows 小工具：**检测到指定设备（外接屏幕 / USB）连接时，自动开启（或关闭）系统"移动热点"**，并给出右下角通知。

适用于这类场景：插上办公桌上的外接屏（如 Dell E2423H）→ 电脑自动共享网络给手机；插上某个 USB 设备（如串口工具、USB 摄像头）→ 自动开热点。屏幕触发与 USB 触发**相互独立、严格分离**。

## 功能特性

- **双类触发，互不混淆**：屏幕触发项只匹配显示器（PnP ID / 名称），USB 触发项只匹配 USB 设备（VID/PID），可各配多个触发项
- **每个触发项独立动作**：可设"开热点"或"关热点"
- **电源门控（可选，默认开）**：仅在接通电源（插电）时执行触发动作；开机时若在用电池，程序在后台待机（托盘提示"待机(未插电)"），插上电源后自动恢复监控
- **现代化暗色设置界面**：分页签配置（屏幕触发 / USB 触发 / 通用设置），当前连接的设备以 `●` 标记并自动选中，误选"历史设备"会弹警告
- **托盘图标监控**：事件驱动（设备变化立即响应）+ 兜底轮询，低占用（实测约 50 MB），运行满 N 分钟自动退出（待机期间不计时）
- **启动延时（默认 2 分钟）**：打开软件后先驻留托盘、不检测不退出，给你时间先右键托盘 → 设置配置触发项；延时结束才开始执行规则
- **通知策略克制**：只在"触发设备连接并执行了动作"、"监控超时自动退出"或"进入/恢复待机"时发一次通知
- **单文件 exe**：无需安装任何运行时（仅需系统自带的 .NET Framework 4.x），不弹控制台窗口

## 系统要求

- Windows 10 / 11（移动热点基于系统自带功能）
- 管理员权限（开启热点需要，程序会自动请求提权；开机自启动任务已配最高权限）
- 首次请先在系统设置里开启过一次"移动热点"并配置好名称/密码

## 快速开始

1. 双击 `HotspotGuard.exe` 打开设置（或命令行 `HotspotGuard.exe config`）
2. **屏幕触发**页：列表顶部是当前插着的屏幕（`●` 开头），选中后点"▶ 添加为触发"
3. **USB 触发**页：先插上目标 USB 设备再打开设置，从列表选择（显示 VID/PID）
4. **通用设置**页：按需调整"最长运行分钟"、"启动延时"等选项，点"保存"
5. 运行监控：双击 exe（默认 watch 模式，先进入启动延时便于配置）或设为开机自启动（见下）
6. 若双击后想先配置：延时期间**右键右下角托盘图标 → "设置(触发设备)..."** 即可，不会秒退

## 触发规则

> 两种运行模式：**boot（开机自启）= 立即检测执行**；**watch（手动双击打开）= 先按"启动延时"驻留便于配置**。

| 情形 | 动作 |
|---|---|
| 手动打开(watch)后的启动延时内（默认 2 分钟） | 驻留托盘不检测，可先配置；延时结束开始执行规则 |
| 开机自启(boot) | 跳过启动延时，立即检测执行 |
| 任一屏幕触发项连接 | 执行该触发项动作（默认开热点）→ 通知 → 退出 |
| 任一 USB 触发项连接 | 同上（只匹配 USB，与屏幕无关） |
| 检测到**未配置**的外接屏 | 不做任何操作，直接退出并通知（提示如何添加） |
| 长时间无触发设备 | 运行满 N 分钟（默认 5）自动退出并通知 |
| **未插电（用电池）**（启用"仅接电触发"时） | 后台待机，不执行任何动作、不退出；接通电源后自动恢复监控 |

## 命令行

```
HotspotGuard.exe [watch|boot|once|status|config|start|stop|help]
  watch    托盘监控(手动打开默认): 先按启动延时驻留便于配置, 延时后执行规则
  boot     托盘监控(开机自启用): 跳过启动延时, 立即检测执行
  once     检测一次并执行后退出
  status   查看当前屏幕/USB 设备与热点状态
  config   图形化设置
  start    立即开启热点
  stop     立即关闭热点
```

## 开机自启动

- 双击 `install-task.bat`（自动请求管理员权限）注册"登录触发 + 最高权限"的计划任务，以 **boot 模式**运行（开机立即检测，不受手动启动延时影响）
- 双击 `uninstall-task.bat` 移除

## 文件与日志

- 配置：exe 同目录 `hotspotguard.json`（设置界面生成，已加入 .gitignore）
- 日志：exe 同目录 `hotspotguard.log`
- PowerShell 备份版：`hotspotguard.ps1`（功能与 exe 一致，供无 .NET Framework 环境的旧系统使用）

## 从源码构建

```
powershell -ExecutionPolicy Bypass -File src\build.ps1
```

编译原理：使用系统自带 .NET Framework csc + GAC facade 程序集 + Windows WinMetadata (winmd) 直接编译 WinRT 代码，**无需安装 .NET SDK**。
